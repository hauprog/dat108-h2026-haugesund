# DAT108 h26, campus Haugesund

Kode fra forelesningene i DAT108 (Programmering og webapplikasjoner) høsten 2026, ved campus Haugesund.
Felles kodeeksempler for alle campus ligger i:
https://github.com/lars-petter-helland/dat108-h2026

## LockedIn

Demospillet vi bygger sammen gjennom semesteret: Ole utforsker et nedlagt sykehus.
Spillet vokser litt hver forelesning, og hver forelesning er merket med en tag:

    git checkout f01     # slik koden var etter F01
    git checkout main    # nyeste

Åpne mappen `LockedIn/` som prosjekt i IntelliJ (JDK 25).

## Bruk

Koden er ment å leses, kjøres og kopieres fra. Bruk gjerne biter av den i
semesterprosjektet deres, men skriv om det dere kopierer så dere skjønner det.
