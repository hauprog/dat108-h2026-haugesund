# Øving uke 41 (F15 og F16)

Seks små oppgaver med en Spring-controller. Hver oppgave har en test som er rød til den er løst.

1. **Åpne** mappen `oving-uke41` i IntelliJ (File > Open, velg mappen). Vent til Maven er ferdig nederst til høyre.
2. **Finn oppgavene:** `OvingController.java`, eller TODO-vinduet (Alt+6, på Mac Cmd+6).
3. **Kjør testen** for oppgaven du jobber med: høyreklikk `Oppgave1Test` under `src/test/java`, Run. For å kjøre alle på en gang høyreklikker du `src/test/java` og trykker Run på 'All Tests'.
4. **Står du fast:** hint i tre trinn på ukessiden (lenke i Canvas og på Discord).
5. **I nettleseren:** kjør `OvingApplication` og åpne <http://localhost:8080>. Testene trenger ikke at serveren kjører.

Ferdig når alle testene er grønne. Fasit på taggen `oving-uke41-fasit`.
